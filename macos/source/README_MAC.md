# macOS 说明

macOS 的安装、使用、补丁、恢复和源码构建说明见 [README.md](README.md)。发布程序为 Universal 应用，支持 macOS 12 或更高版本的 Apple 芯片与 Intel Mac。

XIASS Tools 启动时会自动、安全地同步 `~/.gemini` 下所有旧 Antigravity 会话目录。同步只新增缺失文件，不覆盖共享目录中的现有会话。

从旧版“Antigravity WF助手”升级时，安装器不会静默删除旧 App 或用户数据；请先退出旧 App，确认 XIASS Tools 正常启动后，再由你决定是否删除旧 App。
