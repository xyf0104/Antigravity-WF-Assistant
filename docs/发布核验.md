# v1.4.5 发布核验

此清单区分本地已完成的回归验证与由 GitHub 标签发布工作流强制完成的构建、安装包和校验步骤。只有两个平台都构建成功后，工作流才会创建公开 Release。

## 已完成的本地回归

- [x] macOS 和 Windows 源码均通过 `go test -race -count=1 ./...`。
- [x] 两端前端均通过 OAuth 状态、OAuth 登录体验与更新检查测试。
- [x] 账户同步在账户删除或连接路由变更期间不会写入过期绑定；已有直连模型在账户池不可用时会回退原有凭据。
- [x] 上游模型发现和测试错误会隐藏已配置的凭据与自定义请求头值。
- [x] `VERSION`、Wails 产品版本、前端版本、更新器、安装包名称和 README 下载名称均为 `1.4.5`。
- [x] 本机已构建 macOS Universal 应用与 `v1.4.5` 安装器；核验二进制包含 `x86_64` 和 `arm64`、应用 Bundle ID/版本正确、安装包载荷包含标准 Applications 应用。

## GitHub 标签发布工作流

- [ ] 以 `v1.4.5` 标签触发 macOS Universal 与 Windows x64 的干净构建。
- [ ] 每个平台在发布前执行前端构建、三项前端测试和 Go race 测试。
- [ ] 生成且只上传 `Antigravity-WF-Assistant-macOS-universal-v1.4.5-Installer.pkg`、`Antigravity-WF-Assistant-Windows-x64-v1.4.5-Setup.exe` 与由新构建产物生成的 `SHA256SUMS.txt`。
- [ ] 下载发布产物并核验清单内容与两个文件名、SHA-256 完全对应。

## 安装后抽检

- [ ] macOS：确认安装到 `/Applications`、Dock/菜单栏驻留、退出释放端口及 Antigravity 启动。
- [ ] Windows：确认开始菜单、可选桌面快捷方式、通知区域驻留、退出释放端口及 Antigravity 启动。
- [ ] 在真实账户上确认“一键同步全部模型”后，可在 Antigravity 直接选择模型并正常发送请求。
