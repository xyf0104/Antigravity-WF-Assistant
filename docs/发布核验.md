# v1.4.20 发布核验

`v1.4.20` 为当前待发布版本；`v1.4.19` 为上一正式发布版，`v1.4.6` 为保留的稳定回退基线。发布目录只保留两个平台的标准安装包与其校验清单。

## 已核验的发布一致性

- [x] macOS 与 Windows 的 `VERSION`、Wails 产品版本、前端版本、更新器版本、应用内版本显示和安装器版本均为 `1.4.20`。
- [x] `v1.4.20` 已补齐自定义图片模型的模型协议能力声明与图片模型索引。
- [x] `v1.4.20` 的 v4 图片预览兼容补丁会严格匹配 Antigravity `1.23.2` 已知渲染器结构，支持 `generatedMedia`、`generatedImage`、`inlineData`、Base64 与本地 `file://` URI。
- [x] 旧 v2 / v3 补丁可升级到 v4；ASAR 与 `app.asar.unpacked` renderer 都会保留原始备份、失败回滚和显式恢复语义。
- [x] 旧端点补丁但缺少图片预览补丁的安装会显示为“待补丁”；未知渲染器结构不会阻断常规补丁或误报待补丁。
- [ ] 标签 `v1.4.20`、两个平台安装包和同次发布的 `SHA256SUMS.txt` 待 CI 完成构建后生成。

## 发布后的安装抽检

- [ ] macOS：确认安装到 `/Applications`、Dock/菜单栏驻留、退出释放本地代理及 Antigravity 启动。
- [ ] Windows：确认开始菜单、可选桌面快捷方式、通知区域驻留、退出释放本地代理及 Antigravity 启动。
- [ ] 使用真实账户确认账户同步后的自定义模型可在 Antigravity 下拉框中选择并正常发送请求。

## 发布内容

- macOS Universal：`Antigravity-WF-Assistant-macOS-universal-v1.4.20-Installer.pkg`
- Windows x64：`Antigravity-WF-Assistant-Windows-x64-v1.4.20-Setup.exe`
- 完整性校验：`SHA256SUMS.txt`

如需回退，可使用上一正式版 `v1.4.19` 或保留的 `v1.4.6` 发布包；不要使用历史本机构建号 `1.4.16`。
