## 文件校验

GitHub Release 附带 `SHA256SUMS.txt`。下载后可运行：

```bash
shasum -a 256 -c SHA256SUMS.txt
```

Windows PowerShell 可运行：

```powershell
Get-FileHash .\Antigravity-WF-Assistant-Windows-x64-v1.3.0-Setup.exe -Algorithm SHA256
```
