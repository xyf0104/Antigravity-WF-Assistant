# v1.4.24 发布核验清单

本清单是 `v1.4.24` 的发布门槛，不是已经完成的测试报告。只有所有与目标平台相关的项目通过后，才可创建标签 `v1.4.24`、上传安装包和发布 GitHub Release。

## 版本与发布物

- [ ] Windows 与 macOS 的 `VERSION`、Wails 产品版本、前端 `package.json` / lockfile、界面版本标签、更新器 `CurrentVersion` 和 Windows NSIS 版本资源均为 `1.4.24`。
- [ ] GitHub 标签严格为 `v1.4.24`；标签与两个 `VERSION` 文件一致。
- [ ] 仅发布下列同次构建产物，且 `SHA256SUMS.txt` 与实际文件逐字节相符：
  - `Antigravity-WF-Assistant-macOS-universal-v1.4.24-Installer.pkg`
  - `Antigravity-WF-Assistant-Windows-x64-v1.4.24-Setup.exe`
- [ ] Release 不上传独立 portable 可执行文件、用户配置、账户 JSON、API Key、Token、Cookie、聊天记录或未脱敏运行日志。

## 自动化与构建

- [ ] 两端前端均完成 `npm ci`、`npm run build`、模型分组、推理能力、OAuth 状态 / UX 和更新检查测试。
- [ ] 两端均完成 `go test -race ./... -count=1` 与 `go vet ./...`。
- [ ] Windows 完成 Wails x64 和 NSIS `Setup.exe` 构建；macOS 完成 Wails Universal App 和 `.pkg` 构建。
- [ ] 发布工作流验证标签与 `VERSION` 后，成功上传两个安装器和由工作流生成的 `SHA256SUMS.txt`。

## 图片路由与 renderer 回归

- [ ] 使用脱敏测试上游验证：自定义 GPT 图片模型生成图片后，图片自动展示、默认展开并显示 GPT 标题。
- [ ] 同一轨迹切换回原生 Gemini 后验证：后续 native `image_gen` 请求不调用先前的自定义图片上游，图片正常展示并显示 Gemini 标题。
- [ ] 验证已知 Gemini、通用 Gemini、未知图片模型和模型缺失时的标题与折叠状态；验证图片粘贴/识图/文件路径不回归。
- [ ] 验证已知旧 patch marker 的升级、原始备份识别、失败回滚和“恢复原始文件”。
- [ ] 对每个实际目标安装的 renderer 先做只读迁移和 `node --check`；不向未知结构写入补丁。

## 实机安装抽检

- [ ] macOS：安装到 `/Applications` 后确认 Launchpad / Dock、菜单栏打开与退出、退出释放本地代理、配置和历史会话保留、自动发现与启动 Antigravity。
- [ ] Windows：确认开始菜单、可选桌面快捷方式、通知区域打开与退出、退出释放本地代理、配置和历史会话保留、自动发现与启动 Antigravity。
- [ ] 在至少一个已验证 Antigravity renderer 结构上，确认自定义模型出现在下拉框、可发送文字和图片请求；未知 renderer 结构必须安全跳过图片界面补丁，而不是导致 Antigravity 卡死。

## 兼容政策

自动发现覆盖常见安装位置、运行进程及平台目录。代理协议和模型注入会尽量复用已支持的请求形状；renderer 图片预览补丁则只能在严格匹配的结构上启用。不能以“任何未来版本均保证可补丁”为发布承诺：新版本出现未知 renderer 时，必须先补充 fixture、自动化测试与实机验收。
