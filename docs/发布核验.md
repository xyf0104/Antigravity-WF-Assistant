# v1.4.19 发布核验

`v1.4.19` 为当前正式发布版；`v1.4.6` 为保留的稳定回退基线。发布目录只保留两个平台的标准安装包与其校验清单。

## 已核验的发布一致性

- [x] macOS 与 Windows 的 `VERSION`、Wails 产品版本、前端版本、更新器版本、应用内版本显示和安装器版本均为 `1.4.19`。
- [x] 当前 Git 标签仅保留 `v1.4.6` 和 `v1.4.19`；当前正式发布标签为 `v1.4.19`。
- [x] 当前发布目录仅包含 macOS Universal `.pkg`、Windows x64 `Setup.exe` 与 `SHA256SUMS.txt`。
- [x] 顶层发布目录中的两个安装包均已通过 `SHA256SUMS.txt` 校验。
- [x] `v1.4.19` 已将模型推理等级解析、账户池协议隔离和更新器版本同步纳入双端源码与测试覆盖范围。

## 发布后的安装抽检

- [ ] macOS：确认安装到 `/Applications`、Dock/菜单栏驻留、退出释放本地代理及 Antigravity 启动。
- [ ] Windows：确认开始菜单、可选桌面快捷方式、通知区域驻留、退出释放本地代理及 Antigravity 启动。
- [ ] 使用真实账户确认账户同步后的自定义模型可在 Antigravity 下拉框中选择并正常发送请求。

## 发布内容

- macOS Universal：`Antigravity-WF-Assistant-macOS-universal-v1.4.19-Installer.pkg`
