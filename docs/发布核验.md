# v1.5.2 发布核验清单

本清单是 v1.5.2 的发布门槛，不代表尚未执行的项目已经通过。Windows 与 macOS 必须同时显示并发布为 1.5.2；Windows 仅允许同步版本元数据和重新构建，功能逻辑必须保持已验收的 v1.5.1 行为。

## 版本与源码边界

- [ ] GitHub 标签严格为 `v1.5.2`。
- [ ] macOS 的 `VERSION`、Wails 产品版本、前端 `package.json` / lockfile、界面版本和更新器 `CurrentVersion` 均为 `1.5.2`。
- [ ] Windows 的 `VERSION`、Wails 产品版本、前端 `package.json` / lockfile、界面版本、安装器 FileVersion / ProductVersion 和更新器 `CurrentVersion` 均为 `1.5.2`。
- [ ] 审查 `git diff v1.5.1 -- windows`：除版本元数据、安装器版本和发布名称外，不得出现 Windows 业务功能逻辑变化。
- [ ] Windows 的代理、账户、模型、补丁、图片、OAuth、历史、托盘和退出逻辑与已验收 v1.5.1 保持一致。
- [ ] 不提交 API Key、Token、Cookie、账户 JSON、用户模型配置、聊天记录、构建缓存或未脱敏日志。

## 测试与构建

- [ ] macOS 前端完成 `npm ci`、生产构建、模型分组、推理能力、OAuth 状态 / UX、连接进度 UX 和更新检查测试。
- [ ] macOS 完成 `go test ./... -count=1`、`go test -race ./... -count=1` 和 `go vet ./...`。
- [ ] macOS 完成 Wails Universal App 与 `.pkg` 构建，并确认主可执行文件同时包含 `arm64` 和 `x86_64`。
- [ ] Windows 在干净 Windows x64 构建环境中完成前端测试、生产构建、`go test ./... -count=1`、`go test -race ./... -count=1` 和 `go vet ./...`。
- [ ] Windows 从已验收 v1.5.1 功能源码加 1.5.2 版本元数据重新构建 Wails x64 与 NSIS Setup，不复用或改名 v1.5.1 二进制。
- [ ] 两个平台安装包的内部产品版本、安装后界面版本和在线更新版本均实际显示 `1.5.2`。

## 连接、模型与图片回归

- [ ] 在已验证的 Antigravity IDE 结构上测试“全部连接”“仅连接 IDE”“恢复原机配置”，并确认失败事务完整回滚。
- [ ] 在已验证的 Antigravity 2.0 结构上测试“仅连接 Antigravity 2.0”、启动、退出、恢复和安装完整性。
- [ ] 自定义模型能够出现在 Antigravity 下拉框，文字、截图粘贴、图片识别、文件、PDF 和工具调用正常。
- [ ] 自定义图片模型生成后自动展示、默认展开并显示实际模型标题；Prompt 缩略图保留，正文不重复显示同一大图。
- [ ] 同一轨迹切回原生 Gemini 后，后续原生图片请求不继承此前的自定义图片来源。
- [ ] Claude 工具调用、工具结果关联、上下文去重和流式回复正常，不出现无断线条件下的循环回复。
- [ ] 对所有实际目标的 renderer、ASAR、Language Server 和完整性字段先做只读结构验证；未知结构保持零写入并显示原因。

## 安装与桌面行为

- [ ] macOS `.pkg` 安装到 `/Applications` 后可从 Launchpad、Finder、Dock 和顶部菜单栏打开。
- [ ] macOS 点击关闭按钮后窗口最小化/隐藏但程序继续运行；Dock 与菜单栏“退出”均能真正结束进程并释放本地代理。
- [ ] Windows Setup 可正常安装、升级覆盖和卸载，并可按用户勾选创建桌面快捷方式。
- [ ] Windows 点击关闭按钮后驻留右下角通知区域；通知区域“打开主界面”和“退出”均正常，退出释放本地代理。
- [ ] 两个平台重新安装或升级助手后，账户、模型、设置和历史会话保持不丢失。
- [ ] 端口冲突时能安全释放助手自身旧监听；无法释放时切换到新的本机端口，并保证代理、补丁和状态使用同一端口。

## 发布资产

- [ ] Release 标题为 `Antigravity WF助手 v1.5.2`。
- [ ] Release 只上传以下两个安装包和一个安全更新校验清单：
  - `Antigravity-WF-Assistant-macOS-universal-v1.5.2-Installer.pkg`
  - `Antigravity-WF-Assistant-Windows-x64-v1.5.2-Setup.exe`
  - `SHA256SUMS.txt`
- [ ] 不额外上传 portable、独立 EXE、ZIP、配置、日志、测试报告或调试材料。
- [ ] 发布前分别计算两个安装包的 SHA-256，写入 `SHA256SUMS.txt` 和 Release 正文，并再次从 Release 下载核对。
- [ ] Release 上传使用三个精确文件路径，不使用可能混入其他文件的通配符。

## 最终验收

- [ ] 在一台非开发环境 Windows 10/11 x64 电脑上完成安装、连接、模型同步、Antigravity 启动、文字、工具、识图、生图、托盘退出和卸载抽检。
- [ ] 在一台非开发环境 Apple Silicon Mac 和一台 Intel Mac 或等价隔离环境中完成相同抽检。
- [ ] GitHub `releases/latest` 指向 v1.5.2，客户端“检查更新”能在合理时间内识别该版本、下载对应平台安装包并正确重启。

## 兼容政策

兼容性以实际安装结构为准，不承诺对所有未来版本无条件写入。新版本出现未知 renderer、ASAR、Language Server 或完整性字段时，必须先补充脱敏 fixture、自动化测试和实机验收；在此之前显示不支持原因并保持零写入。
