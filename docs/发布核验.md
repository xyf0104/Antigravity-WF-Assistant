# v1.4.4 发布待验收清单

本清单记录 v1.4.4 在发布前仍需完成的构建、自动化工作流与真实设备验收；不代表安装包已经构建或发布。

## 通用功能

- [ ] 每张账户卡片都可单独打开测试：API Key、OAuth、JSON 导入与 Claude 账户均只测试当前账户。
- [ ] 测试窗口能获取当前账户的模型；模型获取失败时，仍能明确提示并允许选择安全默认测试模型。
- [ ] 点击取消或关闭测试窗口后，正在进行的测试请求会被真正取消，不继续占用测试请求；迟到结果不会写回界面。
- [ ] OpenAI / Codex OAuth 账户只走其适用的直连请求路径，不会把 OAuth 凭据降级发送到 Chat Completions 路径。
- [ ] OpenAI / Codex 账户的模型获取、可显示的账号信息与额度窗口在可用时正常更新；凭据不会显示在界面或日志中。
- [ ] 更新检查在网络可用时快速返回；短时间内使用最近成功缓存，网络超时或失败时给出明确状态且不阻塞界面。

## 发布前文件校验（待生成产物后）

- [ ] 为两个安装包生成 `SHA256SUMS.txt`。

```bash
shasum -a 256 -c SHA256SUMS.txt
```

- [ ] 在 Windows PowerShell 校验安装器：

```powershell
Get-FileHash .\Antigravity-WF-Assistant-Windows-x64-v1.4.4-Setup.exe -Algorithm SHA256
```

- [ ] 确认 Release 仅包含两个标准安装包及 `SHA256SUMS.txt`，并将本文件中的待验收项逐项完成。
