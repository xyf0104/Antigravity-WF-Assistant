# v1.4.1 发布核验

## macOS

- `npm run build`：通过。
- `go test ./...`：通过。
- Wails `darwin/universal` 构建：通过。
- 主程序架构：`x86_64 arm64`。
- Bundle ID：`com.wufeng.antigravity-wf-assistant`。
- App 版本：`1.4.1`。
- `codesign --verify --deep --strict`：通过。
- PKG payload 文件检查：通过；应用固定安装到 `/Applications/Antigravity WF助手.app`，组件不再包含可迁移 bundle，避免被错误重定向到其他目录。
- 安装器默认不创建桌面快捷方式；勾选后才创建，且不会覆盖桌面中已有同名项目。
- 点击窗口关闭按钮后隐藏主窗口并只保留顶部菜单栏图标；菜单栏“退出”会先停止代理并释放 `127.0.0.1:50999`。

## Windows

- `npm run build`：通过。
- `GOOS=windows GOARCH=amd64 go test -exec true ./...`：所有包交叉编译通过。
- Wails `windows/amd64` 主程序构建：通过。
- 主程序格式：PE32+ GUI x86-64。
- NSIS 单文件安装器构建：通过，无构建警告；“在桌面创建快捷方式”为可选组件。
- GitHub Actions 会在真实 Windows 环境执行测试、Wails 打包与 NSIS 生成，并只产出 Setup 安装程序；发布前需等待该工作流成功。
- 点击窗口关闭按钮后隐藏主窗口、不再显示于任务栏；右下角通知区域图标可打开主界面或退出并释放端口。

Windows 程序在 macOS 上只能完成交叉编译、PE 格式与安装包结构检查；最终运行体验仍建议在真实 Windows 10/11 x64 环境做一次安装、补丁、启动、恢复和卸载验收。

## 文件校验

GitHub Release 附带 `SHA256SUMS.txt`。下载后可运行：

```bash
shasum -a 256 -c SHA256SUMS.txt
```

Windows PowerShell 可运行：

```powershell
Get-FileHash .\Antigravity-WF-Assistant-Windows-x64-v1.4.1-Setup.exe -Algorithm SHA256
```
