# v1.3.3 发布核验

## macOS

- `npm run build`：通过。
- `go test ./...`：通过。
- Wails `darwin/universal` 构建：通过。
- 主程序架构：`x86_64 arm64`。
- Bundle ID：`com.wufeng.antigravity-wf-assistant`。
- App 版本：`1.3.3`。
- `codesign --verify --deep --strict`：通过。
- App 实际启动与正常退出冒烟测试：通过。
- DMG `hdiutil verify`、挂载后签名与架构检查：通过。
- ZIP 解压测试、解压后签名与架构检查：通过。
- PKG `pkgutil --check-signature` 与 payload 文件检查：通过；安装器默认不创建桌面快捷方式，勾选后才创建且不会覆盖桌面中已有同名项目。
- 点击窗口关闭按钮：通过；窗口最小化到 Dock，代理继续运行。
- 侧栏电源按钮调用 Wails 正常退出路径；生命周期单元测试已覆盖“普通关闭拦截 / 明确退出放行”。新进程独占端口时，现有 `OnShutdown → proxy.Stop()` 会释放 `127.0.0.1:50999`。

## Windows

- `npm run build`：通过。
- `GOOS=windows GOARCH=amd64 go test -exec true ./...`：所有包交叉编译通过。
- Wails `windows/amd64` 主程序构建：通过。
- 主程序格式：PE32+ GUI x86-64。
- NSIS 单文件安装器构建：通过，无构建警告；“在桌面创建快捷方式”为可选组件。
- GitHub Actions 会在真实 Windows 环境执行测试、Wails 打包与 NSIS 生成，并产出 Setup 和 Portable EXE；发布前需等待该工作流成功。

Windows 程序在 macOS 上只能完成交叉编译、PE 格式与安装包结构检查；最终运行体验仍建议在真实 Windows 10/11 x64 环境做一次安装、补丁、启动、恢复和卸载验收。

## 文件校验

GitHub Release 附带 `SHA256SUMS.txt`。下载后可运行：

```bash
shasum -a 256 -c SHA256SUMS.txt
```

Windows PowerShell 可运行：

```powershell
Get-FileHash .\Antigravity-WF-Assistant-Windows-x64-v1.3.3-Setup.exe -Algorithm SHA256
```
