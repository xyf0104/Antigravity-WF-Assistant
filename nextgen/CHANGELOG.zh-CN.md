# 更新日志

## [1.7.5] - 2026-09-01

### 修复

- 隔离本地 CLI 代理运行时的认证状态，避免新账号会话继承其他运行时的认证目录或模型注册状态。
- 修复 GitHub Hosted Runner 上 Windows 安装包生命周期校验调用不兼容 `Close()` 方法的问题；MSI 和 Setup 仍会先校验离线 WebView2 载荷，再执行干净安装、应用启动、bridge 启动和卸载验证。
- 修复 Windows MSI 生命周期校验中带空格的安装包与日志路径未显式引用、可能导致 `msiexec` 无界面等待的问题。
- 恢复五个工作台中 Cockpit 原有的账户、OAuth、2FA、额度、供应商模板、模型发现与测试等入口；XIASS 改动仅承担品牌与视觉材质，不再替换原有功能或布局。
- 统一 macOS 与 Windows 内嵌 WF 前端、公开资源、桥接合同和版本投影，并在发布预检中加入逐字节跨平台一致性校验。

## [1.7.4] - 2026-09-01

### 修复

- 保留 Windows 离线 WebView2 安装依赖；修复 GitHub Hosted Runner 缺少旧式 ICE 脚本引擎时 WiX 3.14 无法链接 MSI 的问题。构建仍会对官方 WiX 工具包 SHA-256 校验，并继续执行安装包解包、安装、启动与本地 bridge 冒烟验证。

## [1.7.3] - 2026-09-01

### 修复

- Windows Server 2025 映像在 WiX 3.14 链接 MSI 时连续失败，Windows 安装包构建改为固定使用稳定的 Windows Server 2022 runner。

## [1.7.2] - 2026-09-01

### 新增

- macOS 与 Windows 均支持标准 TOTP 二维码和 Google Authenticator 迁移二维码的可恢复导入，支持多图片分批、乱序导入与凭据去重。
- Antigravity OAuth 支持 PKCE、回调自动接收、重启恢复和手动粘贴回调地址兜底。

### 变更

- 所有 Agent 统一保留 Cockpit 原有的侧栏、账号标题、平台切换器、标签栏与整页滚动层级；XIASS 功能只融合进对应 Agent 页内。
- 内嵌 macOS / Windows 助手的版本源与桌面发布版本统一。

### 修复

- macOS 主程序与两个本地 sidecar 均以 Universal 形式打包，并增加从 DMG 安装、启动的烟雾检查。
- 嵌入工作台首帧跟随当前主题，且继续使用单一 XIASS 主滚动区域。

## [1.7.1] - 2026-08-31

### 新增

- 为 Antigravity WF、Codex、Claude Code、Cursor 与 Windsurf 分别提供一个默认中文的融合工作台。
- 增加 Antigravity 本地代理、模型、生图、账号、补丁、诊断与启动流程的完整应用内手册。
- 增加界面可访问性、配置持久化、Tauri 命令接线、显式退出和真实前端就绪发布门禁。

### 变更

- 统一采用 XIASS API 深海背景、透明品牌标识、四周圆角液态玻璃，并完整适配浅色、深色与跟随系统主题。
- 按钮、页签、弹窗和表单操作统一为至少 44px 的可点击目标，并补齐悬停、键盘焦点、按下、禁用和加载状态。
- 改进窄工作区、125% 缩放、长中文、URL 表单、弹窗层级与 Codex 会话工具栏的响应式布局。
- 调整 macOS 生命周期：点红色关闭按钮后保留后台服务，显式退出时关闭桥接并释放本地端口。

### 修复

- 修复供应商和账号配置读取异常时可能静默覆盖现有数据的问题。
- 修复 WF bridge 在主程序退出后未完整停止代理和释放监听端口的问题。
- 修复 macOS CI / 更新器启动配置，并以 React 实际提交作为前端就绪信号，杜绝只有进程、没有界面的空壳构建通过门禁。
- 隔离 Rust 测试中的共享环境变量，使完整工作区在默认并行测试模式下稳定通过。
- 修复仪表盘标题对比度、远程 MCP 表单裁切、小尺寸或无名称按钮、弹窗可访问性和嵌入页首帧主题闪烁。

## [1.7.0] - 2026-08-31

### 新增

- 统一管理 Antigravity、Codex、Claude Code、Cursor、Windsurf 及其他受支持客户端的本地账号。
- 为受支持的平台提供 OAuth 授权、自动回调与手动粘贴回调兜底。
- 提供安全本地账号存储、额度展示、账号测试、导入导出和实例管理。

### 变更

- 桌面应用、数据目录和公开服务默认值统一调整为 XIASS Tools。
- 以只读兼容方式迁移历史版本的账号数据、快捷方式、扩展存储和内部协议标识。

### 修复

- 移除上游广告、公告和私有远程配置请求。
- 改进双平台安装迁移与 OAuth 启动进度展示。
