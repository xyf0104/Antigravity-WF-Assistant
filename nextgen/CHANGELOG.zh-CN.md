# 更新日志

## [1.7.1] - 2026-08-31

### 新增

- 为 Antigravity WF、Codex、Claude Code、Cursor 与 Windsurf 分别提供一个默认中文的融合工作台。
- 增加 Antigravity 本地代理、模型、生图、账号、补丁、诊断与启动流程的完整应用内手册。
- 增加界面可访问性、配置持久化、Tauri 命令接线、显式退出和真实前端就绪发布门禁。

### 变更

- 统一采用 XIASS API 深海背景、透明品牌标识、四周圆角液态玻璃，并完整适配浅色、深色与跟随系统主题。
- 按钮、页签、弹窗和表单操作统一为至少 44px 的可点击目标，并补齐悬停、键盘焦点、按下、禁用和加载状态。
- 改进窄工作区、125% 缩放、长中文、URL 表单、弹窗层级与 Codex 会话工具栏的响应式布局。
- 调整 macOS 生命周期：点红色关闭按钮后保留后台服务，显式退出时关闭桥接并释放本地端口。

### 修复

- 修复供应商和账号配置读取异常时可能静默覆盖现有数据的问题。
- 修复 WF bridge 在主程序退出后未完整停止代理和释放监听端口的问题。
- 修复 macOS CI / 更新器启动配置，并以 React 实际提交作为前端就绪信号，杜绝只有进程、没有界面的空壳构建通过门禁。
- 隔离 Rust 测试中的共享环境变量，使完整工作区在默认并行测试模式下稳定通过。
- 修复仪表盘标题对比度、远程 MCP 表单裁切、小尺寸或无名称按钮、弹窗可访问性和嵌入页首帧主题闪烁。

## [1.7.0] - 2026-08-31

### 新增

- 统一管理 Antigravity、Codex、Claude Code、Cursor、Windsurf 及其他受支持客户端的本地账号。
- 为受支持的平台提供 OAuth 授权、自动回调与手动粘贴回调兜底。
- 提供安全本地账号存储、额度展示、账号测试、导入导出和实例管理。

### 变更

- 桌面应用、数据目录和公开服务默认值统一调整为 XIASS Tools。
- 以只读兼容方式迁移旧 Cockpit 账号数据、快捷方式、扩展存储和内部协议标识。

### 修复

- 移除上游广告、公告和私有远程配置请求。
- 改进双平台安装迁移与 OAuth 启动进度展示。
